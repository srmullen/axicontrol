## Agent skills

### Issue tracker

Issues are taipir tasks: markdown files in `tasks/`, tracked through taipir lanes (backlog → todo → in-progress → review → done → cancelled) and triage tags. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles map to taipir tags using their default names (needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
